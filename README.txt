NUCLEAR SYSTEM — installable PWA

GitHub Pages par deploy:
1. Is zip ki SAARI files (index.html, sw.js, manifest.webmanifest, icons/ folder, .nojekyll) repo ke root me upload karo (purani files replace).
2. Pages ke live hone ka 1-2 min wait karo.
3. Phone Chrome me link kholo -> 2 baar reload -> menu (⋮) -> "Install app".
   (Pehle se "shortcut" bana hua ho to use delete kar do.)
4. Ek baar online khol lo, uske baad app offline bhi chalegi.

Google login ke liye Firebase Console -> Authentication -> Settings -> Authorized domains me
<username>.github.io add hona chahiye.
